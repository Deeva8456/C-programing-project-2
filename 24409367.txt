WF2fillFromKeyboard(int arr[], int capacity)

Prompts the user to enter integers one by one. When the user enters a negative number, input stops.
All remaining positions in the array are filled with UNUSED_MARKER to indicate they are not used.
This allows dynamic input but still keeps a fixed array size.

WF3_fillRandom(int arr[], int size, int capacity, int min, int max)

Automatically fills part of the array with random integers between min and max.
If size is smaller than the total capacity, the remaining elements are marked unused.
This function is useful for testing the rest of the system without manual input.

WF4_clearArray(int arr[], int capacity)
Resets all elements to the special unused marker value (UNUSED_MARKER).
This provides a quick way to clear old data before refilling or reusing the array.

WF5_sortArray(int arr[], int capacity)
Sorts all used elements (those before the first unused marker) in ascending order using a bubble sort algorithm.
After sorting, unused elements remain grouped at the end.
Sorting ensures other statistical functions (like median) can work correctly.

WF6_randomizeArray(int arr[], int capacity)
shuffle all used elements into a random order 

 WF7_printUsed(const int arr[], int capacity)
Prints only the “used” portion of the array (up to the first unused marker) in { } format.
Used to verify that fill, sort, or randomize operations worked correctly.

WF8_printAll(const int arr[], int capacity)
Prints the full contents of the array, including unused elements, to show its internal state.
This helps visualize how much of the array is filled and where unused markers start.

WF9_minElement(const int arr[], int capacity)
Scans through all used elements of the array and finds the smallest (minimum) value.
It starts with the first valid element as the initial minimum, then compares every other used element against it.

If the array has no used elements (e.g., all marked with UNUSED_MARKER), the function returns the marker itself to indicate an empty dataset.

WF10_maxElement(const int arr[], int capacity)
Similar to WF9_minElement(), this function finds the largest (maximum) used value in the array.
It initializes a variable max with the first used element, then iterates through all valid elements, updating max whenever a larger value is found.

This function uses the MAX2(a, b) macro to select the larger of two numbers

WF11_average(const int arr[], int capacity)
Calculates the arithmetic mean (average) of all used elements.
It adds up all valid elements, then divides the total by the count of used elements.
If there are no used elements, the function returns 0.0.

WF12_median(const int arr[], int capacity)
Finds the median value (the middle value when the data is sorted).
The function first copies all used elements into a temporary array and sorts them using a bubble sort
If the number of used elements is odd, the middle element is returned.
If it’s even, the median is the average of the two middle elements.
If there are no used elements, the function returns 0.0.

WF13_variance(const int arr[], int capacity)
Computes the variance, which measures how much the data values differ from the average.
The function first calculates the mean using WF11_average(), then computes the sum of squared differences between each used element and the mean.
The total is then divided by the number of used elements to give the variance

WF14_stddev(const int arr[], int capacity)
Calculates the standard deviation, which is the square root of the variance.
This function calls WF13_variance() internally, then applies the square root (sqrt) to the result.

WF15_countUsed(const int arr[], int capacity)
Counts the number of “active” (non-unused) elements in the array.
It stops counting when it reaches the first UNUSED_MARKER.
This function is frequently used by sorting, randomizing, and statistical routines to only process valid elements.
