# C-programing-project-2
Integer Array Analysis

Project Description

This project involves developing a modular C program using Microsoft Visual Studio to create and analyse arrays of integers.

The program allows users to fill arrays with keyboard input or random numbers, sort and randomize elements, clear arrays, and display used or all elements. It also calculates statistical values, including the minimum, maximum, average, median, variance, and standard deviation.

The application uses a text-based menu to demonstrate the different array operations.

Technologies Used

C Programming Language

Microsoft Visual Studio

Doxygen Documentation

Key Features

Generate random integers within a specified range.

Fill and clear arrays.

Sort and randomize array elements.

Display array contents.

Calculate statistical values.

Use modular programming with separate source and header files.

Project Documentation

The project includes Doxygen comments, generated HTML documentation, and a text report containing the module structure, function prototypes, specifications, and pseudocode.

How to Run

Open the Visual Studio solution, build the project, and run the application. Use the text menu to select the desired operation.
