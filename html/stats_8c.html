Compute median of used elements using bubble sort. Copies used elements into a temporary array, sorts them,and computes the median. The median is the middle value in a data set after sorting from lowest to highest.

Computes the median of elements in an array.

  • If the number of used elements is odd, the median is the single middle number.
  • If the number of used elements is even, the median is the average of the two middle numbers.
    Parameters
    arrInput integer array
    capacitySize of the array
    Returns
    Median value as a double or 0.0 if array is empty.
